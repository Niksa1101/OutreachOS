# `core/api/`

The typed HTTP client and the only place the backend auth token exists on the
frontend.

The token is held in a module-scoped binding that is **not exported**. The fetch
wrapper and the SSE client both close over it. It is never placed in React state,
never in a Zustand store, and never in `localStorage` — anything reachable from a
component eventually ends up in someone's debug `console.log`.

Policy: 15s default timeout via `AbortController` (overridable per call, SSE
exempt), no automatic retry, and a 401 refetches backend info via `invoke` once
and retries that request exactly once before surfacing `unauthorized`.

`schema.d.ts` is generated by `scripts/gen-api-types.mjs` and committed. Never
hand-edit it; CI fails if it is stale relative to the Pydantic models.
