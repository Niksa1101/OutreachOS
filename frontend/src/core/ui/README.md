# `core/ui/`

Custom components, **composed from** shadcn primitives — never replacing them.

Per PRD §3: check the shadcn registry before writing anything here. Buttons,
dialogs, dropdowns, tables, tabs, sliders, tooltips, toasts, sheets, sidebars,
forms, popovers, selects, switches, and progress bars all come from shadcn.

Styling uses design tokens exclusively. Hardcoded colors and spacing values are a
review failure.
